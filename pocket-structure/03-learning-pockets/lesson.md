# 3장 · 딥러닝은 포켓을 어떻게 알아볼까?

[조작 가능한 그림과 함께 보기](https://chahero.github.io/abstain-dti-learning/pocket-structure/03-learning-pockets/)

개념도는 설명용이며 DeepPocket·GrASP의 실제 추론 출력이 아닙니다. 2장의 실제 fpocket·P2Rank 계산과 구분합니다.

## 1. 딥러닝은 포켓을 어떻게 알아볼까?

### 질문은 같고, 읽는 방식이 다릅니다

2장의 질문은 **“이 단백질의 어디가 붙을 만한 자리일까?”**였습니다. 이번 두 기술도 원자의 3차원 배치를 보고 포켓을 찾습니다.

**DeepPocket**은 fpocket이 제안한 자리 주변을 작은 상자들로 나누어, 3차원 이미지처럼 읽습니다. **GrASP**는 주변 원자들을 점과 연결선으로 표현하고, 이웃의 정보를 모아 읽습니다.

P2Rank도 이미 머신러닝 방법입니다. 이번에는 단지 ‘AI를 추가한다’기보다, **주변 환경을 조합해 표현하는 방식**을 신경망으로 학습한다는 차이에 주목합니다.

원자 좌표 → 모델이 읽는 표현 → 평가 → 포켓 후보.

이번 장은 원 논문과 공개 구현에 근거한 개념 학습입니다. 두 딥러닝 모델의 새 추론은 실행하지 않았습니다.

## 2. 모델은 ‘포켓답다’를 어디서 배울까?

### 정답이 있는 사례로 기준을 배웁니다

**학습(training)**에서는 이미 리간드가 결합한 실험 구조를 참고해, 어떤 후보·공간·원자가 결합 부위에 해당하는지 표시합니다. 이 표시를 **라벨(label)**이라고 합니다.

모델은 단백질에서 예측한 결과와 라벨의 차이를 줄이도록 내부 수치를 바꿉니다. DeepPocket의 후보 분류·영역 분할과 GrASP의 표면 원자 평가는 서로 다른 라벨 정의를 사용합니다.

**예측(inference)**에서는 학습된 모델을 고정하고 새 단백질을 넣습니다. 이때 찾으려는 리간드의 위치를 정답으로 알려 주지 않습니다.

비슷한 단백질이 학습·평가 양쪽에 들어 있으면 성능이 좋아 보일 수 있습니다. ‘새 구조’와 ‘학습에서 충분히 낯선 구조’는 같은 뜻이 아닙니다.

학습 때 참고한 정답을, 실제 예측 때 입력하는 것은 아닙니다.

## 3. 원자 좌표를 3차원 이미지로 바꾸려면?

### 픽셀의 입체 버전, 복셀

사진을 작은 사각형 **픽셀(pixel)**로 나누듯, 3차원 공간은 작은 상자 **복셀(voxel)**로 나눌 수 있습니다. 복셀마다 주변 원자의 정보를 숫자로 기록합니다.

**채널(channel)**은 같은 위치의 정보를 종류별로 나누어 담는 칸입니다. RGB 사진이 색 채널 3개를 쓰듯, 원자 유형별 채널을 쓸 수 있습니다. 단순히 ‘원자 한 개를 상자 하나에 넣는다’보다, 주변으로 퍼진 원자 밀도를 기록하는 표현에 가깝습니다.

**3D CNN**은 작은 입체 필터를 여러 위치에 적용해, 근처 원자들의 배치 패턴을 읽는 신경망입니다. 필터의 수치는 학습으로 정해집니다.

복셀은 공간의 칸, 채널은 정보의 종류, CNN은 주변 패턴을 읽는 방법입니다.

DeepPocket의 실제 격자 크기

논문의 분류 입력은 원자 유형 채널 14개와 공간 격자 48×48×48입니다. 간격은 0.5 Å이고 양 끝 격자점 사이 길이는 23.5 Å입니다. 영역 분할은 별도의 65×65×65 격자(32 Å)를 씁니다. 채널은 단순 원소 이름보다 세분된 원자 유형입니다.

## 4. DeepPocket은 fpocket 다음에 무엇을 할까?

### 후보 생성과 판단을 나누었습니다

- **fpocket으로 후보를 찾습니다.** 알파 구들로 제안된 각 포켓의 중심을 얻습니다.

- **후보 중심 주변을 격자로 바꿉니다.** 단백질 원자의 유형과 배치를 CNN이 읽을 수 있게 표현합니다.

- **분류 CNN으로 다시 평가합니다.** 각 후보가 결합 부위일 만한지 점수를 매겨 순서를 다시 정합니다.

- **상위 후보의 영역을 분할합니다.** 별도의 신경망으로 공간의 어느 부분이 포켓인지 예측합니다.

**처음부터 단백질 전체를 자유롭게 탐색하는 단일 모델은 아닙니다.** 후보를 놓친 경우 재순위화만으로 빠짐없이 복구된다고 볼 수 없습니다.

fpocket의 후보 제안 위에, CNN의 재평가와 영역 분할을 얹습니다.

[공식 구현의 예측 절차](https://github.com/devalab/DeepPocket#predicting-binding-site)

## 5. ‘어디인가’와 ‘어디까지인가’는 다릅니다

### 분류는 판단, 분할은 색칠

**후보 분류(classification)**는 “이 후보가 유망한가?”를 묻습니다. 점수와 순위가 있어도 포켓의 정확한 범위가 정해지는 것은 아닙니다.

**영역 분할(segmentation)**은 “각 복셀이 포켓 영역에 속하는가?”를 묻습니다. 공간 칸별로 값을 예측하고, 포켓으로 선택된 영역을 **마스크(mask)**로 나타낼 수 있습니다.

DeepPocket의 분할 모델은 **U-Net과 비슷한 구조**입니다. 공간을 줄여 넓은 문맥을 읽고, 다시 해상도를 복원합니다. 중간 단계 정보를 건너 연결해 위치 정보를 보완합니다.

분할 결과는 예측된 결합 공간입니다. **그 안에서 특정 화합물이 취할 자세나 친화도를 곧바로 계산한 결과는 아닙니다.**

중심 한 점을 찾는 것과, 공간의 범위를 예측하는 것을 구분합니다.

## 6. 원자를 점과 연결선으로 읽는다면?

### 그래프는 관계를 담는 자료 구조입니다

**노드(node)**는 점, **간선(edge)**은 점 사이의 관계입니다. 여기서 노드는 **수소를 제외한 원자**입니다. 아미노산 잔기 하나를 노드 하나로 쓰는 모델과 구분합니다.

GrASP는 공간상 **5 Å 이내 원자 쌍**을 연결합니다. 서열에서 멀리 떨어진 잔기의 원자도, 단백질이 접혀 가까워지면 이웃이 됩니다. 연결선은 공유 결합만을 뜻하지 않습니다.

각 원자에는 전하·잔기 종류 등의 정보가, 연결에는 거리·결합 정보가 붙습니다. 원래 좌표를 버려 2차원으로 예측하는 것이 아니라, **3차원 거리 관계를 그래프에 담는 것**입니다.

실제 GrASP 입력은 **용매에 노출된 표면 원자와 그 주변 5 Å 이내의 내부 원자**입니다. 내부 이웃은 환경을 설명하고, 포켓 점수는 표면 원자에 부여합니다.

복셀은 공간을 나누고, 그래프는 원자와 이웃 관계를 연결합니다.

## 7. 이웃 원자의 정보를 어떻게 모을까?

### 소식을 모아 내 표현을 갱신합니다

**메시지 패싱(message passing)**은 이웃의 정보를 받아 모은 뒤, 자신의 숫자 표현을 갱신하는 과정입니다. 한 층을 거치면 바로 옆 이웃, 여러 층을 거치면 그 너머 이웃의 정보도 반영됩니다.

**어텐션(attention)**은 모든 이웃을 같은 비중으로 더하지 않고, 어느 이웃의 정보를 얼마나 반영할지 학습하는 방식입니다. 원자와 연결의 특징에 따라 비중이 달라집니다.

이 과정을 수행하는 신경망을 **GNN(Graph Neural Network, 그래프 신경망)**, 어텐션을 쓰는 종류를 **GAT(Graph Attention Network)**라고 부릅니다.

**큰 어텐션이 강한 화학 결합이나 중요한 원인이라는 뜻은 아닙니다.** 모델 내부에서 정보를 섞는 비중이며, 물리적 에너지나 인과관계와 동일하지 않습니다.

‘어떤 원자인가’에 ‘어떤 이웃을 가졌는가’를 더해 판단합니다.

GrASP 블록을 조금 더 자세히

GATv2 기반 어텐션 헤드 4개, 메시지 합계·평균의 조합, 이전 층 정보를 보존하는 연결을 사용합니다. 학습 시 잡음을 복원하는 보조 과제도 사용합니다. 입문 도식은 이 전체 연산을 단순화한 것입니다.

## 8. GrASP는 원자 점수에서 포켓을 어떻게 만들까?

### 공간 칸 대신, 표면 원자를 평가합니다

- **표면 주변 그래프를 만듭니다.** 표면 원자와 안쪽 이웃에 원자·잔기·거리 정보를 넣습니다.

- **GAT로 주변 환경을 학습된 방식으로 모읍니다.** 여러 층의 정보 교환으로 각 원자의 표현을 만듭니다.

- **표면 원자별 결합 부위 점수를 예측합니다.** 학습 시에는 알려진 리간드와의 거리를 바탕으로 연속적인 라벨을 만듭니다.

- **선택된 원자들을 묶어 후보를 만듭니다.** 가까운 원자 무리를 포켓으로 정리하고 점수를 종합해 순위를 매깁니다.

이름은 **Graph Attention Site Prediction**입니다. fpocket 후보를 먼저 받을 필요 없이 표면 원자 평가에서 후보를 만듭니다.

그래프 → 정보 교환 → 표면 원자 점수 → 포켓 무리와 순위.

논문의 후처리 기준

논문은 원자 점수 0.3을 넘는 원자들을 average-linkage clustering(두 무리 사이 평균 거리를 쓰는 군집화)으로 묶습니다. 포켓 점수는 구성 원자 점수의 제곱합이며, 중심은 원자 군집의 볼록 껍질로 구합니다. 이 임계값과 점수는 특정 화합물의 결합 확률이나 친화도가 아닙니다.

[원 논문 · Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC11182664/)

## 9. fpocket·P2Rank와 무엇이 다를까?

### 모델 이름보다, 판단의 단위를 봅니다

DeepPocket은 **fpocket과 연결되는 방법**입니다. GrASP는 P2Rank처럼 표면 환경을 평가하지만, **표면점이 아닌 원자**를 평가하고 주변 정보를 신경망으로 조합합니다.

GrASP가 3차원 정보를 덜 쓴다는 뜻도, DeepPocket이 항상 더 낫다는 뜻도 아닙니다. **입력 표현·후보 생성·학습 데이터·평가 조건**이 함께 달라집니다.

[2장에서 실제로 실행한 fpocket·P2Rank 결과 다시 보기 →](../02-pocket-detection/#step-7)

단백질 구조를 받는 네 방법의 핵심 차이 · 숫자 점수는 서로 직접 비교하지 않습니다.

| 비교 기준 | fpocket | P2Rank | DeepPocket | GrASP |
| --- | --- | --- | --- | --- |
| 주로 읽는 단위 | 원자 사이 빈 공간의 알파 구 | 용매 접근 표면의 점 | 후보 주변의 원자 유형별 3D 격자 | 표면 주변의 원자·거리 그래프 |
| 후보를 만드는 방법 | 구를 선별하고 묶음 | 표면점 평가 후 묶음 | **fpocket 후보부터 시작** | 표면 원자 평가 후 묶음 |
| 판단의 핵심 | 기하학·물리화학 특성 기반 점수 | 정의된 주변 특징 + 랜덤 포레스트 | 3D CNN 재평가 + U-Net형 영역 분할 | GAT로 이웃 표현 학습 + 원자 점수 |
| 대표 출력 | 알파 구·관련 원자·포켓 순위 | 표면점·중심·관련 잔기·순위 | 재정렬 후보·공간 분할·관련 잔기 | 원자 점수·원자 군집·중심·순위 |

가상 구 / 표면점 / 공간 칸 / 표면 원자 — 무엇을 평가하는지부터 구분합니다.

## 10. 두 기술을 네 문장으로 정리합니다

- 01 **DeepPocket은 후보 주변을 3D 이미지로 읽습니다.**

fpocket 후보 → 격자 → CNN 재평가 → 별도 영역 분할.

- 02 **GrASP는 표면 주변을 원자 그래프로 읽습니다.**

이웃 정보 교환 → 표면 원자 점수 → 포켓 후보 묶기.

- 03 **학습 모델도 입력 구조와 데이터에 영향을 받습니다.**

주어진 구조에서 자리를 찾는 것이지, 닫힌 포켓을 자동으로 열거나 단백질을 새로 접는 것은 아닙니다.

- 04 **포켓 점수와 특정 약의 친화도는 다릅니다.**

좋은 후보를 찾는 것과 실제 결합·효능을 확인하는 것은 다른 단계입니다.

더 복잡한 모델인가보다, 무엇을 읽고 어떤 질문에 답하는가를 봅니다.

## 출처와 자료 범위

출처·용어·이 자료의 범위

그림은 직접 작성한 학습용 SVG 개념도입니다. 복셀의 값, 어텐션 비중, 원자 색과 후보 순서는 설명용이며 실제 모델 출력이 아닙니다. 원 논문과 공개 구현을 읽어 정리했고, DeepPocket·GrASP의 모델 가중치 추론이나 성능 재현은 실행하지 않았습니다. 2장의 fpocket·P2Rank 실제 결과와 구분합니다.

이 장의 GrASP는 Smith 등의 **Graph Attention Site Prediction**(2024)입니다. 이름이 비슷한 GRaSP-web(잔기 이웃 그래프 기반의 다른 연구)과 구분합니다. 딥러닝이 모든 데이터에서 기존 방법보다 낫다고 단정하지 않습니다. GrASP의 거리 기반 표현은 회전 불변성을 갖도록 설계되었지만 모든 GNN이 자동으로 같은 성질을 갖는 것은 아닙니다.

**복셀·채널**: 3차원 공간의 작은 칸 · 한 위치에 종류별로 기록하는 정보

**CNN**: Convolutional Neural Network · 국소 패턴을 읽는 합성곱 신경망

**분할·마스크**: 위치마다 영역 소속을 예측하는 일 · 선택된 공간 표시

**GNN·GAT**: Graph Neural Network · 어텐션으로 이웃 정보를 모으는 Graph Attention Network

**중원자**: 수소를 제외한 원자. 여기서는 그래프의 노드 단위
