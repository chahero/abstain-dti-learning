# HOTPocket / hotpocketNN

The Human Omnibus of Targetable Pockets

Journal of Cheminformatics · 정식 저널 공개 2025-12-24 · 저널 게재

> 여러 탐지기의 후보를 모으고, 공통 학습 점수로 선별해 인간 단백질의 포켓 지도를 만듭니다.

입력: 단백질 3D 구조 + 여러 탐지기의 후보

출력: 후보별 점수·선별 포켓·통합 지도

## 왜 했나?

서로 다른 도구가 제안한 후보를 어떻게 함께 활용할까?

## 어떻게 하나?

여러 탐지기의 후보 잔기에 대한 ESM-2 특징을 hotpocketNN이 읽어 점수를 매깁니다. 후보를 선별·군집화한 예측 지도와 이를 만드는 모델을 함께 제공합니다.

1. **7개 탐지기의 후보** — 실험·AlphaFold2 구조에 여러 검출기를 적용합니다.

2. **hotpocketNN** — 후보 잔기 특징으로 공통 점수를 계산합니다.

3. **HOTPocket 지도** — 후보를 선별·묶어 인간 proteome의 예측 지도를 만듭니다.

설명용 예시: 여러 사람이 찾아온 장소를 한 기준으로 심사하는 상황입니다. 추천 목록을 단순히 합치는 것과, 공통 기준으로 선별하는 것은 다릅니다.

## 논문에서 보고한 내용

- 인간 단백질 전반의 대규모 예측 포켓 자료와 후보 선별 모델을 공개했습니다.
- Astex·PoseBusters에서는 좋은 결과를 보고했지만, Human BioLiP의 일부 포켓 평가에서는 P2Rank가 더 좋았습니다. 통합이 항상 최선이라는 결론은 아닙니다.

## 해석의 한계

- HOTPocket은 예측 지도·파이프라인이고 hotpocketNN은 선별 모델입니다.
- 예측 포켓 수를 실험 검증된 약물 표적 수로 읽지 않습니다. 입력 구조와 후보의 품질에도 의존합니다.

## 용어

- **앙상블**: 여러 방법의 결과를 활용하는 접근.
- **proteome**: 한 생물의 단백질 전체 집합.
- **재점수화**: 기존 후보를 다른 기준으로 다시 평가하는 일.

## 원문 그림을 볼 때

후보를 만든 원래 도구와, 그 후보를 평가하는 hotpocketNN을 분리해서 보세요. 최종 지도는 선별·군집화까지 거친 결과입니다.
