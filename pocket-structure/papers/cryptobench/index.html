01 · 문제의식

리간드가 빠진 결합 상태 구조가 아니라, 실제 apo 구조에서도 숨은 부위를 찾을까?

02 · 작동 원리

핵심 아이디어와 처리 흐름

같은 단백질의 apo–holo 구조를 대응시키고 숨은 결합 부위를 정리합니다. 학습·평가 분할과 기준 방법을 함께 제공합니다.

  1. apo–holo 구조 쌍

    같은 단백질의 비결합·결합 구조를 대응시킵니다.

  2. 숨은 부위·분할

    구조 변화와 단백질 유사도를 고려해 평가 자료를 준비합니다.

  3. 예측 평가

    apo 입력에서 부위를 찾는 성능을 비교합니다.

설명용 예시

닫힌 방을 찍은 사진에서 나중에 문이 열릴 자리를 맞히는 문제입니다. 열린 방 사진에서 사람만 지운 뒤 평가하는 문제와는 입력 조건이 다릅니다.

03 · 논문에서 보고한 내용

무엇을 보여 주었나?

  • 저자들은 대규모 숨은 결합 부위 자료와 학습·평가 분할을 공개하고 pLM-NN·PocketMiner·P2Rank 같은 방법을 평가했습니다.
  • 핵심 기여는 실제 apo 조건과 일관된 기준으로 새 방법을 시험할 토대입니다.
