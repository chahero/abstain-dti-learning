붙을 자리, 컴퓨터는 어떻게 찾을까?

단백질의 좌표를 보고 결합 공간의 후보를 찾는 과정을 배웁니다.

1. 붙을 자리, 컴퓨터는 어떻게 찾을까?

이번에는 리간드를 모릅니다

1장에서는 맥아당이 결합한 위치를 알고 단백질을 보았습니다. 이번 질문은 “리간드가 보이지 않아도 어디에 붙을 만한지 찾을 수 있을까?”입니다.

포켓 탐지 도구는 단백질의 3차원 정보를 받아 여러 결합 공간 후보를 찾고, 유망해 보이는 순서대로 정리합니다.

여기서 찾는 것은 붙을 자리입니다. 특정 화합물이 어떤 자세로 들어가는지, 얼마나 강하게 결합하는지는 이후에 다룰 다른 질문입니다.

출력은 한 개의 확정 정답이 아니라 포켓 후보들입니다.

2. 좌표·표면·후보·중심·순위를 먼저 익힙니다

도구를 읽기 위한 다섯 단어

좌표 · coordinate
각 원자가 놓인 x, y, z 위치입니다. Å(옹스트롬)은 길이 단위이며 1 Å은 0.1 nm입니다.
표면 · surface
단백질 바깥쪽 경계입니다. 작은 물 분자가 원자 주위를 지나갈 수 있는 위치를 기준으로 정의하기도 합니다.
후보 · candidate
결합 공간일 가능성이 있어 도구가 제안한 영역입니다.
중심 · center
복잡한 포켓의 위치를 대표하는 한 점입니다. 포켓 전체 모양은 담지 못합니다.
순위와 점수 · rank / score
도구가 후보를 정렬하는 기준입니다. 점수가 높다는 뜻은 점수의 정의에 따라 해석합니다.

점수의 숫자보다 무엇을 점수화했는지 먼저 봅니다.

3. fpocket은 빈 공간을 어떻게 찾을까?

빈 공간에 가상의 공을 놓습니다

알파 구(alpha sphere)는 3차원에서 네 원자에 닿으면서 내부에 다른 원자가 없는 가상의 구입니다. fpocket은 보로노이 분할이라는 기하학적 방법으로 이 구들을 찾습니다.

너무 작거나 큰 구를 걸러 낸 뒤, 가까이 모인 구들을 하나의 공간 후보로 묶습니다. 이것이 클러스터링입니다. 구 하나가 곧 포켓 하나인 것은 아닙니다.

마지막에는 크기와 주변의 물리·화학적 특징 등을 요약한 특성값(descriptor)으로 후보의 순위를 매깁니다. 후보를 만드는 중심 원리는 기하학이지만, 점수에 화학적 특징도 반영됩니다.

fpocket: 빈 공간을 찾고, 모아서, 순위를 매깁니다.

4. P2Rank는 표면에서 무엇을 볼까?

표면에 점을 찍고 주변을 평가합니다

P2Rank는 용매가 접근할 수 있는 단백질 표면에 점들을 배치합니다. 각 점 주변의 원자 종류, 노출 정도, 기하학과 화학적 환경 등을 숫자 특징으로 만듭니다.

이미 알려진 단백질·리간드 복합체로 학습한 랜덤 포레스트(Random Forest)가 이 특징을 보고 결합 부위다운지 평가합니다. 여러 결정 나무의 판단을 모으는 머신러닝 모델입니다.

평가가 좋은 주변 점들을 묶어 포켓 후보를 만들고 순위를 정합니다. 여기서는 기존에 학습된 모델을 실행하며, MBP로 새 모델을 학습시키지는 않습니다.

P2Rank: 표면의 환경을 학습된 기준으로 평가합니다.

주요 출력알파 구, 주변 원자, 특성값, 순위표면점, 관련 잔기, 중심, 점수와 순위

둘 다 구조의 기하학을 사용합니다. fpocket도 점수에 화학적 특징을 쓰므로 ‘모양만 보는 도구 대 화학만 보는 도구’로 나누면 부정확합니다.

서로 다른 점수는 크기를 직접 비교하지 않습니다. fpocket 0.241과 P2Rank 37.43이 나와도, 37.43이 더 큰 결합력이라는 뜻은 아닙니다.

같은 입력에서도 후보를 만드는 단위와 평가 기준이 다릅니다.

6. 맥아당을 가리고 같은 입력을 넣었습니다

1장에서 본 MBP를 그대로 씁니다

기준은 실험 구조 1ANF입니다. 원본에서 맥아당과 물을 빼고 단백질 chain A의 원자 —개를 같은 좌표와 실험 정보 그대로 남겼습니다.

이 파일을 각각 fpocket과 P2Rank의 기본 설정으로 계산했습니다. 두 도구에는 원래 맥아당의 위치를 알려 주지 않았습니다.

리간드를 지워도 단백질의 모양은 그대로입니다. 따라서 이 입력은 ‘리간드가 제거된 holo 유래 구조’입니다. 실제 리간드 없는 apo 실험 구조인 1OMP와 구분합니다.

계산을 마친 뒤 원본의 맥아당 위치를 다시 표시해 결과를 비교합니다. 화면의 사슬 선은 보기 위한 요약이고, 계산에는 전체 단백질 원자 좌표를 사용했습니다.

같은 입력으로 예측하고, 기준 위치는 나중에 공개합니다.

7. 실제로 어디를 찾았을까?

실제 계산 결과를 불러오는 중입니다.

fpocket

청록색 반투명 구: 실제 출력 알파 구 · 십자: 그 구들 중심의 평균

P2Rank

파란 점: 실제 출력 표면점 · 십자: 도구가 보고한 포켓 중심

입력은 동일한 1ANF 단백질 좌표입니다. 후보를 바꾸면 각 도구가 찾은 다른 공간을 볼 수 있습니다.

사슬은 잔기당 기준점(Cα) 하나의 추적도입니다. 두 화면은 동일한 시점과 배율을 사용합니다. 구·점·맥아당의 위치는 실제 좌표이며, 단백질 표면이나 결합 자세를 새로 예측한 그림은 아닙니다.

8. 같은 단백질의 다른 모양을 넣으면?

한 번 찾았다고 끝은 아닙니다

실제 apo 구조인 1OMP에도 맥아당과 물이 없는 단백질 입력을 만들어 같은 설정으로 계산했습니다. 두 도구 모두 1ANF 때와 다른 개수의 후보를 만들었습니다.

입력의 입체 모양과 실험 정보가 바뀌면 결과도 달라질 수 있습니다. 이 두 사례만으로 한 방법이 더 정확하거나 더 일반화한다고 말할 수는 없습니다.

포켓 후보가 있다는 것, 특정 화합물이 결합한다는 것, 강하게 결합한다는 것은 별개입니다. P2Rank의 probability나 fpocket의 druggability 점수를 특정 화합물의 결합 확률·친화도로 읽으면 안 됩니다.

결과를 읽을 때는 구조 상태와 점수의 뜻을 함께 봅니다.

9. 공통 개념에서 두 기술의 차이까지

  1. 01
    포켓 탐지는 결합 공간의 후보를 찾습니다.

    원자의 좌표가 입력이고, 후보 영역·중심·순위 등이 출력입니다.

  2. 02
    fpocket은 가상 구로 공간을 찾습니다.

    구를 선별하고 묶은 뒤 포켓 특성으로 순위를 정합니다.

  3. 03
    P2Rank는 표면의 환경을 학습 모델로 평가합니다.

    표면점 주변 특징 → 랜덤 포레스트 → 후보 묶기와 순위입니다.

  4. 04
    같은 입력의 실제 결과도 표현과 점수가 다릅니다.

    후보 수와 숫자의 크기만으로 우열이나 친화도를 판단하지 않습니다.

도구 이름보다 입력·원리·출력의 뜻을 연결해 기억합니다.
