# 2장 · 붙을 자리, 컴퓨터는 어떻게 찾을까?

단백질 포켓과 결합 구조 예측 · 개인 학습용 자료

## 1. 무엇을 예측하는가?

1장에서는 맥아당이 붙은 위치를 알고 단백질을 보았다. 이번에는 리간드가 보이지 않는 상태에서 단백질의 어디에 결합 공간이 있을지 찾는다. 도구는 원자 좌표에서 여러 포켓 후보와 순위를 제안한다. 특정 화합물의 결합 자세를 찾는 도킹, 결합 여부 예측, 친화도 예측은 구분해서 공부한다.

## 2. 공통 개념

| 용어 | 뜻 |
|---|---|
| 좌표 | 원자의 x, y, z 위치 |
| Å, 옹스트롬 | 길이 단위. 1 Å = 0.1 nm |
| 표면 | 단백질 바깥 경계. 용매 접근성을 기준으로 정의하기도 함 |
| 후보 | 결합 공간일 가능성이 있어 도구가 제안한 영역 |
| 중심 | 복잡한 공간의 위치를 대표하는 한 점 |
| 순위 | 도구가 후보들을 정렬한 순서 |
| 점수 | 후보를 정렬하기 위해 정의한 수치. 도구마다 정의가 다름 |
| 클러스터링 | 가까운 점·구를 한 무리로 묶는 과정 |
| 특징·특성값 | 크기나 주변 환경을 숫자로 표현한 정보 |

중심점 하나는 포켓 전체의 모양을 표현하지 못한다. 점수가 크다는 말을 해석하기 전에는 무엇에 관한 점수인지 확인한다.

## 3. fpocket의 방법

fpocket은 단백질 원자 사이의 빈 공간을 기하학적으로 찾는다. 핵심 단위인 알파 구는 3차원에서 네 원자에 닿으며 내부에 다른 원자가 없는 가상의 구다. 실제 원자나 리간드가 아니다.

보로노이 분할로 구들을 구하고, 너무 작거나 큰 것을 선별한다. 이후 가까운 구들을 묶어 공간 후보를 만들고, 후보의 기하학·물리화학 특성으로 점수와 순위를 계산한다. 이번 실행의 기본 알파 구 반경 범위는 3.4–6.2 Å였다. 버전·설정에 따라 달라질 수 있다.

기억할 흐름: **가상 구 → 선별 → 묶기 → 포켓의 특성값 → 순위**.

## 4. P2Rank의 방법

P2Rank는 용매 접근 가능한 표면에 점들을 배치한다. 주변의 원자와 공간적·화학적 환경을 특징으로 표현해 학습 모델에 넣는다. 표면점도 단백질 원자가 아니라 환경을 평가하는 위치다.

여러 결정 나무의 판단을 합치는 랜덤 포레스트가 점 주변의 환경을 평가한다. 높은 평가를 받은 주변 점들을 묶어 포켓 후보를 만들고 포켓 단위로 점수와 순위를 정한다.

이번에는 이미 학습된 P2Rank 모델로 예측했으며 MBP로 모델을 새로 학습하지 않았다. 실험 X선 구조의 기본 프로파일을 사용했다. AlphaFold 구조에 적용할 때는 그 구조에 맞는 별도 프로파일을 확인해야 한다.

기억할 흐름: **표면점 → 주변 특징 → 학습된 모델 → 묶기 → 순위**.

## 5. 차이와 공통점

| 비교 | fpocket | P2Rank |
|---|---|---|
| 주요 단위 | 빈 공간의 가상 구 | 표면 환경을 평가할 점 |
| 핵심 관점 | 어디에 공간이 생겼는가 | 어떤 표면 환경이 결합 부위다운가 |
| 후보 생성 | 구의 선별과 묶기 | 특징의 학습 모델 평가와 점 묶기 |
| 출력의 예 | 알파 구, 주변 원자, 특성값 | 표면점, 중심, 관련 잔기, 점수 |

둘 다 구조의 기하학을 사용한다. fpocket도 순위 계산에 화학적 특징을 쓰므로 단순히 “모양 대 화학”으로 구분하지 않는다.

## 6. 실제 예시의 입력

1장의 MBP를 재사용했다. 기준 원본은 RCSB의 **1ANF**이다.

1. 원본에서 맥아당과 물을 제거한다.
2. chain A의 단백질 원자 **2,860개**를 남긴다. 좌표와 실험 B-factor는 유지한다.
3. 바이트가 같은 파일을 fpocket과 P2Rank에 각각 입력한다.
4. 예측이 끝난 뒤 원본의 맥아당 원자 23개를 겹쳐 위치를 비교한다.

리간드를 지워도 단백질의 모양이 실제 apo 구조로 바뀌지 않는다. 1ANF 입력은 **리간드 제거된 holo 유래 구조**이며 실제 apo 실험 구조인 1OMP와 구분한다. 도구에 원래 맥아당 위치나 포켓 위치를 알려 주지 않았다. 화면의 Cα 추적도는 보기 위한 요약이고 계산에는 전체 단백질 원자 좌표를 썼다.

## 7. 실제 계산 결과

| 동일한 1ANF 입력 | fpocket | P2Rank |
|---|---:|---:|
| 후보 수 | 21개 | 5개 |
| 1순위 도구 점수 | 0.241 | 37.43 |
| 1순위 가상 구 / 표면점 수 | 구 104개 | 점 135개 |
| 1순위 중심에서 가장 가까운 맥아당 원자까지 | 1.00 Å | 1.53 Å |

두 도구의 1순위 후보는 이 예시에서 맥아당 부근에 놓였다. 이 결과를 전체 성능의 우열로 해석하지 않는다.

- 점수 0.241과 37.43은 정의와 척도가 다르므로 크기를 직접 비교하지 않는다.
- fpocket 중심은 출력 알파 구 중심들의 단순 평균으로 계산했다.
- P2Rank 중심은 출력 CSV의 center_x/y/z를 사용했다.
- 거리는 후보 중심과 맥아당의 수소 제외 원자들 사이 최소 거리다. 정답 판정 임계값은 적용하지 않았다.
- 중심의 정의가 다르므로 작은 거리 차이로 우열을 매기지 않는다.
- 구와 점은 의미가 달라 그 개수를 공통 품질 점수처럼 비교하지 않는다.

웹에서는 후보를 바꾸거나 같은 방향으로 돌려 보고, 원래 맥아당 위치를 켜고 끌 수 있다. 좌표를 회전하는 것은 보기 방향만 바꾸는 동작이며 재계산이나 도킹이 아니다.

## 8. 다른 구조를 넣으면?

같은 MBP의 실제 apo 실험 구조 **1OMP**도 동일한 방식으로 준비해 계산했다.

| 구조 | fpocket 후보 수 | P2Rank 후보 수 |
|---|---:|---:|
| 1ANF, holo 유래 단백질 좌표 | 21 | 5 |
| 1OMP, 실제 apo 단백질 좌표 | 17 | 4 |

두 입력은 좌표와 실험 정보가 달라 모양만의 효과를 분리한 비교는 아니다. 후보 수가 더 많다고 더 정확하다는 뜻도 아니다.

P2Rank의 probability와 fpocket의 druggability는 특정 화합물·단백질 쌍의 결합 확률이나 친화도가 아니다. 포켓 후보 탐지, 결합 여부, 친화도는 각각 다른 질문이다.

## 9. 핵심 정리와 관찰 메모

1. 입력은 구조이고 출력은 공간 후보다.
2. fpocket은 가상 구를 선별하고 묶어 포켓을 만든다.
3. P2Rank는 표면점 주변 환경을 학습 모델로 평가한다.
4. 실제 결과는 점수의 정의와 입력의 구조 상태를 함께 보며 읽는다.

관찰 메모:

- 가상 구와 표면점의 차이를 내 말로 설명하면:
- 후보 1과 다른 후보들을 비교하며 눈에 띈 것은:
- 아직 헷갈리는 용어는:

자료를 읽거나 프로그램을 실행한 것을 사용자 학습 완료로 표시하지 않는다.

## 버전·재현성·자료의 범위

- fpocket: **4.0 Windows 이식판**. 공식 저장소 Windows 지원 논의(#106)에 연결된 XDrugPy 배포 파일을 사용했다. 공식 최신 릴리스 바이너리가 아니다.
- 배포 파일 고정 커밋: `b01ccc0c007d81aa3cc4f1cecded22696dd5bfc8`.
- 바이너리 SHA256: `1c1c8790bd0f7c3e1e6570d7c489232a1cbefa73a3d1fd61cb8632f3d483cc69`.
- P2Rank: **2.5.1**, 실험 X선 구조 기본 프로파일. 두 도구 모두 기본 설정.

- 개인 학습 사례이며 모델 학습 데이터와의 독립성이나 신규 타깃 일반화를 검증하지 않았다.
- 도식은 설명용이고 실제 좌표를 사용한 결과 화면과 구분한다. 이 단계에서 TTS·MP4나 외부 게시를 수행하지 않았다.
