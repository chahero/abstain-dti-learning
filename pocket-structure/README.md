# 단백질 포켓과 결합 구조 예측

[전체 목차](./) · [기술 발전 흐름도](07-technology-summary/?view=evolution#step-1) · [학습 사이트 홈](../)

개요와 1–6장으로 구성한 개인 학습 자료입니다. 포켓의 기본 개념, 포켓 탐지, 숨은 포켓과 분자동역학, 도킹, co-folding을 그림과 실제 입력·결과 예제로 읽습니다. 각 장에 학습 원고, 인쇄, 기술·논문 출처가 있으며 개요에 기술별 연도와 그 기준을 표시합니다.

HTML·CSS·JavaScript와 미리 준비한 JSON·이미지·구조 파일만 사용합니다. 별도 서버 프로그램, TTS API, 모델 추론은 호출하지 않습니다. 관찰 메모는 사용자의 브라우저에만 저장됩니다. 메모가 저장되었다고 학습 완료를 뜻하지 않습니다.

개인 예제·공식 참고 출력·새로 실행하지 않은 원리 그림을 구분하며, 공식 Abstain-DTI 결과나 공식 평가 규약을 뜻하지 않습니다. 원 자료의 출처·권리는 각 장의 출처와 source-manifest.json을 확인하세요. Pretendard 글꼴과 라이선스는 사이트 공통 assets에 있습니다.

## 사이트 유지

같은 폴더 구조로 GitHub Pages의 저장소 루트에 보관합니다. 상대 경로를 사용하므로 프로젝트 사이트의 /abstain-dti-learning/ 경로 아래에서 동작합니다. 개발용 화면 캡처·모델·실행 환경은 포함하지 않습니다. 그림과 원고가 바뀌면 함께 갱신하고, 최신 버전이 캐시에 남지 않도록 변경한 스크립트의 버전도 갱신하세요.

## 실제 좌표 3D 실습실과 그림 확대

[3D 실습실](08-3d-lab/) · [실제 입력·출력 예시](07-technology-summary/#step-3)

MBP의 실험 좌표와 보존된 fpocket·P2Rank 출력을 같은 좌표계에서 회전·확대합니다. 가상 구 하나와 네 원자, 포켓 후보, 표면점, 두 방법 비교를 따로 볼 수 있습니다. 별도의 ABL–이마티닙 예제에는 공식 Vina 입력·출력 자세가 있습니다. 휠 위는 확대, 아래는 축소이며 ＋/− 버튼도 제공합니다.

개요와 1–6장의 61개 그림에는 크게 보기를 제공합니다. 확대창에서 화면 맞춤, 확대·축소, 드래그 이동, Esc 닫기를 사용할 수 있습니다. 16개 기술의 입력·출력 설명에서 저장된 실제 결과와 미실행 출력 형식을 구분합니다. 새 모델 추론이나 친화도 실험을 수행한 결과가 아닙니다.

3D 표시는 로컬에 포함한 3Dmol.js 2.5.5를 사용합니다. [BSD 및 포함 고지](08-3d-lab/vendor/LICENSE), [배포 번들 고지](08-3d-lab/vendor/3Dmol-min.js.LICENSE.txt), [버전·출처·해시](08-3d-lab/vendor/provenance.json)를 함께 보존합니다. 3D 화면은 WebGL이 필요합니다.

## 16개 기술과 논문 핵심 해설

[16개 비교표](07-technology-summary/#step-2) · [포켓 탐지 발전 흐름](07-technology-summary/?view=evolution&flow=pocket#step-1) · [논문 핵심 해설 10편](papers/)

기술 비교표는 포켓 탐지 7개, 숨은 포켓·MD 2개, 도킹 3개, 공동 구조 예측 4개를 다룹니다. HOTPocket/hotpocketNN, Seq2Pocket, ProMoNet/ProMoSite의 입력·출력·역할을 추가했습니다. LIGYSIS 비교 연구·CryptoBench·검출과 순위 분석은 별도 평가·분석 자료로 구분합니다.

발전 흐름도의 밑줄 친 기술 상자와 평가 자료 이름을 누르면 핵심 해설로 이동합니다. 기술 논문 7편과 평가·분석 3편에 문제의식·원리 그림·보고된 결과·한계·쉬운 용어·원문 링크가 있습니다. 해설 원고 다운로드, 관련 교재와 흐름도로 돌아가기, 확대 그림의 논문 링크를 지원합니다. 개요의 최근 연구 탭에는 숨은 포켓·후보 순위·공간적 범위·데이터 평가·리간드 조건을 정리했습니다.

새 논문 해설의 원리 그림 10개도 확대해 볼 수 있습니다. 프리프린트는 동료심사 논문과 구분하고, 실제 실행 결과와 설명용 예시를 나누었습니다.
