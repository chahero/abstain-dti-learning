실습 실행

이미 고정한 원본을 읽으므로 네트워크·모델 가중치 없이 재현한다. study/07_real_dti/splits/README.md에서 정책을 확인한다.

  • ·
  • audit.tsv: 네 분할의 표본·겹침 검사
  • results.json: 배정 파일 해시, 비교 키 정책, 제외된 블록과 최근접 지문

핵심 다섯 가지

  • 원본 ID·SMILES·서열·Y를 보존하고 비교 키와 도구 버전을 기록한다.
  • random/cold-drug/cold-target/cold-both가 어떤 신규성을 묻는지 확인한다.
  • cold-both의 11,940개 교차 블록을 제외 목록으로 유지한다. 성능 비교에서 다른 표본 수를 숨기지 않는다.
  • 정확한 키 분리와 scaffold·지문·상동성 분리는 다르다. 이 배정의 cold-drug 최대 최근접 Tanimoto는 0.7466666667이고 scaffold 겹침은 0이지만, 일반 보장 조건이 아니다.
  • 모수를 배우는 전처리는 train에서만 fit한다. 개발 검증·보정·최종 평가의 데이터 역할을 따로 설계한다.

직접 관찰

study/07_real_dti/splits/observations.md에 같은 쌍과 같은 분자의 겹침이 왜 다른지, 교차 블록을 쓰면 어떤 질문이 바뀌는지, 가까운 구조 이웃이 왜 남는지를 남긴다. 사용자 관찰 기록은 미작성이며 실행·영상 제작을 학습 완료로 표시하지 않는다.

DT01의 47행과 미승인 수치 후보는 그대로 보존했다. 이번에는 실제 TDC DAVIS 표를 자체 알고리즘으로 배정했다. 공식 TDC/Abstain-DTI split 동결이나 모델 성능이 아니다. 원본의 10,000 nM 값은 정확한 개별 측정·음성 라벨로 자동 승인하지 않는다. 실제 서열 정렬은 실행하지 않았다.
