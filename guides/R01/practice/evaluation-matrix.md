# 가상 후보의 평가 표

두 조건 모두 12회 호출한다. narrow는 후보마다 같은 범주를 네 번, diverse는 서로 다른 네 범주를 한 번씩 평가한다.
수치와 도구 결과는 모두 자체 가상 값이며 실제 단백질 성능·친화도·논문의 후보를 나타내지 않는다.

## 관찰할 점

미확인은 나쁜 결과와 다르다. 호출 수가 같아도 확인한 범주는 다르다.
A는 구조 신뢰도 예시 값이 가장 높지만 물리적 충돌 예시도 가장 많다. 한 지표만으로 후보를 고르는 해석이 무엇을 놓치는지 생각해 본다.
각 지표의 단위·방향·검증 조건을 이해하지 않고 값들을 더해 실제 후보의 순위를 정하지 않는다.
