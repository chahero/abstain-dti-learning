# AI Agents That Matter 웹 발표

이 폴더를 GitHub Pages의 같은 위치에 게시하면 됩니다. 미리 제작한 MP3, 장표 PNG, 공개용 타임라인 JSON만 사용하며 API를 호출하지 않습니다. 음성에 이미 Dustin 1.2배속과 문장·장표 사이 쉼이 반영돼 있어 웹 재생 속도는 1.0입니다.

`data/presentation.json`의 장표 시작 시간과 장별 강조 좌표를 `player.js`가 음성의 currentTime에 맞춰 재생합니다. 슬라이드 5의 표 순차 강조와 다른 장의 도식 흐름을 유지합니다. 로컬 경로나 제작 로그는 공개 데이터에 포함하지 않습니다.

개인 학습용 논문 리뷰이며, 공식 프로젝트 결과를 뜻하지 않습니다.
