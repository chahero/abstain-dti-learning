6.5 → 7.0은 단위 환산이 아닙니다. 많은 학습 사례에서 원점수와 실험 정답 사이의 관계를 배운 예측입니다. BIND의 pIC50를 단위만 바꿔 pKd로 만드는 것도 아닙니다.

골라 쓰는 예측

불확실성이 낮은 10%만 유지한 조건에서, 남긴 예측의 MAE가 전체 예측 사용 대비 상대적으로 25.7% 감소했다고 보고합니다.

10% 유지 = 90% 제외입니다. 25.7%를 전체 문제에 대한 오차 감소로 해석하면 안 됩니다. 선택의 이득과 포기한 범위를 함께 봅니다.

어디까지 믿을 수 있을까?

새로운 화합물·타겟과 다른 실험 조건에서도 그대로 통하는지는 추가 검증이 필요합니다. 신뢰성 r은 정답 확률이 아니며, 불확실성이 낮다는 사실만으로 물리적으로 타당한 결합 자세나 실험적 성공을 보장하지 않습니다.

다른 원점수가 어떻게 ‘같은 목표의 예측’이 될까?

여러 단백질·화합물 쌍에서 ‘엔진 점수 네 개 + 실험 친화도 정답 y’를 준비해 학습합니다. 각 엔진의 전용 변환망은 자기 원점수 하나를 받아, 같은 y를 예측하도록 조정됩니다. 논문의 목표는 실험 pKd/pKi이고, 위 가상 예시는 pKd만 사용합니다.

학습할 때여러 쌍의 원점수 → 엔진별 변환망 → 예측 분포
각 예측·결합 분포를 실험 정답 y와 비교 → 변환망과 신뢰성 망을 함께 조정

새 조합을 예측할 때학습한 망을 고정 → 새 원점수와 서열·화합물 특징만 입력
실험 정답 y 없이 평균과 불확실성 출력

따라서 숫자 8.1의 소수점을 옮기거나 단위를 바꿔 7.5로 만드는 것이 아닙니다. 해당 엔진 점수와 실험 친화도 사이의 통계적 관계를 학습하는 것입니다. 같은 원점수를 받은 전용 변환망은 같은 매개변수를 내지만, 별도 신뢰성 망은 서열·화합물 특징에 따라 r을 다르게 낼 수 있습니다.

고정 버전 구현의 변환망은 각 엔진 원점수 1개 → 256 → 128 → 64 → γ·ν·α·β 구조입니다. 네 망은 매개변수를 따로 가집니다. 엔진 점수 자체를 미리 같은 물리 단위로 정규화하는 단계는 보이지 않으며, 데이터 로더의 표준화는 특징 벡터에 적용됩니다. 실험 정답의 nM → M → −log10 변환은 별도의 정답 준비 과정입니다.

이 변환이 완벽하다는 뜻은 아닙니다. 실험 조건·endpoint 차이와 새로운 화합물에서의 일반화는 여전히 검증해야 합니다. 학습의 실제 손실은 단순한 최종 평균 오차만이 아니라, 개별·결합 분포의 Student-t 음의 로그우도와 증거 정규화를 사용합니다. 자세한 학습은 4장, 데이터 준비는 첨부 D에서 봅니다.
