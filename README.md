# Abstain-DTI Learning

Abstain-DTI 러너의 개인 사전 학습 사이트입니다. 신약 발굴 AI의 예측을 언제 믿고 언제 기권할지, 데이터·구조·보정·Agent의 관점에서 순서대로 공부합니다.

현재는 사이트 초기 준비 단계입니다. GitHub Pages용 홈페이지와 학습 자료를 추가하고, 유튜브 업로드가 완료되면 영상별 주소를 연결할 예정입니다.

## 학습 순서

| 순서 | 자료 코드 | 주제 |
|---|---|---|
| 01 | OV01 | DTI와 기권 · 전체 흐름 |
| 02 | ON01 | 단백질과 타겟 · 구조 레코드 |
| 03 | ON03 | 분자 표현 · SMILES와 동일성 |
| 04 | ON02 | 결합 친화도 · 단위와 라벨 |
| 05 | DT01 | 실제 DTI 레코드 · 정제와 검토 |
| 06 | DT02 | 데이터 분할 · 누출과 일반화 |
| 07 | DT03 | 분자·단백질 표현 · baseline |
| 08 | ON04 | 단백질 구조 · confidence와 feature |
| 09 | ST01 | Rosetta · 구조 탐색과 점수 |
| 10 | ST02 | AlphaFold 2 · MSA와 Evoformer |
| 11 | ST03 | AlphaFold 3 · 복합체와 확산 |
| 12 | ON05 | 도킹·co-folding · 출력의 해석 |
| 13 | CAL01 | Calibration·ECE · 확률 보정 |
| 14 | CP01 | Conformal prediction · 예측 집합 |
| 15 | RC01 | 기권 · risk–coverage와 AURC |
| 16 | AG01 | Agent · MCP와 실행 로그 |
| 17 | CU01 | Curation · 쿼리와 난이도 좌표 |
| 18 | AG02 | 교란 하네스 · 단위와 동일성 |
| 19 | EV01 | 반복 평가 · flip과 실패 분석 |
| 20 | R01 | 단백질 설계 Agent · BioDesignBench |

## 저장소에 담을 자료

- 학습 홈페이지와 20편의 목차
- 영상별 썸네일, 챕터와 출처
- 읽기 가이드와 작은 실습 안내

영상은 유튜브 삽입 플레이어로 제공할 예정입니다. 제작용 MP4·원음·로컬 환경 파일은 이 저장소의 추적 대상에서 제외합니다.

## 원 프로젝트

[Abstain-DTI](https://github.com/Pseudo-Lab/abstain-dti)를 참고한 개인 학습 자료이며, 공식 프로젝트 결과나 공식 평가 규약을 뜻하지 않습니다.
