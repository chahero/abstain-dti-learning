# Abstain-DTI Learning

[학습 사이트 열기](https://chahero.github.io/abstain-dti-learning/) · [YouTube 채널](https://www.youtube.com/channel/UCrGVif00d6j8tQgxDhTqgpQ/videos)

신약 발굴 AI의 예측을 언제 믿고, 언제 기권해야 할까? 약물–타겟 상호작용(DTI), 데이터 분할, 단백질 구조, 불확실성 보정, 도구를 쓰는 에이전트의 평가를 순서대로 공부하기 위한 한국어 영상 자료입니다.

**20편 전체의 공개 YouTube 영상이 학습 사이트에 연결되어 있습니다.** 각 편에는 챕터, 읽기 가이드와 작은 실습 자료, 자막 SRT가 함께 제공됩니다.

## 이용 방법

1. 처음 시작한다면 **01 · OV01**에서 전체 흐름을 먼저 살펴보세요.
2. 아래 표의 주제를 누르면 해당 학습 페이지로, YouTube 링크를 누르면 영상으로 바로 이동합니다. 학습 페이지에서는 챕터를 눌러 필요한 구간부터 볼 수 있습니다.
3. 영상 아래의 **읽기 가이드 · 작은 실습**으로 개념과 계산 예제를 확인하고, 필요하면 **자막 SRT**를 내려받으세요.

## 영상과 자료 관리

현재 20편의 영상 연결은 완료되어 있습니다. 영상을 교체할 때는 [data/youtube-videos.json](data/youtube-videos.json)에서 해당 코드의 값을 **11자리 YouTube 영상 ID**로 변경합니다. 전체 주소 대신 ID만 넣고, 나머지 항목은 유지합니다.

현재 연결된 영상의 예시는 다음과 같습니다.

```json
{
  "OV01": "uT9RL_4X12k",
  "ON01": "us4__IvhD_4"
}
```

목차의 순서·주제·챕터·읽기 가이드·자막 경로는 [data/episodes.json](data/episodes.json)에서 관리합니다. 영상은 공개 또는 일부 공개 상태이고 외부 삽입이 허용되어야 합니다.

## GitHub Pages 운영

이 저장소는 **Settings → Pages → Deploy from a branch → main → /(root)**로 배포합니다. 변경 사항을 `main`에 푸시하면 Pages가 다시 배포됩니다. 루트의 `index.html`과 `.nojekyll`을 유지하며, 별도 Node/Python 서버나 빌드 명령은 필요하지 않습니다.

자료별 주소로도 공유할 수 있습니다. 예를 들어 [AlphaFold 2 학습 페이지](https://chahero.github.io/abstain-dti-learning/?episode=ST02), [같은 영상의 2분 지점](https://chahero.github.io/abstain-dti-learning/?episode=ST02&t=120)처럼 자료 코드와 시작 시간을 지정합니다.

## 자료 범위와 출처

[Pseudo-Lab/abstain-dti](https://github.com/Pseudo-Lab/abstain-dti)를 참고한 **Abstain-DTI 러너의 개인 사전 학습 자료**이며, 공식 프로젝트 결과나 공식 평가 규약을 뜻하지 않습니다. 논문·데이터·도구의 출처는 각 읽기 가이드에서 확인할 수 있습니다.

합성 예제, 실제 데이터 일부에 대한 계산, 모델 추론 실행 여부를 구분해 읽어 주세요. 실습 결과를 읽는 것과 사용자의 이해·학습 완료는 별개입니다.

MP4, 원음, 모델 가중치, 제작·음성 검수 로그와 로컬 환경은 이 저장소에 포함하지 않습니다. 영상은 YouTube에서 제공하며, 이 저장소에는 학습 사이트와 관련 자료를 보관합니다.
