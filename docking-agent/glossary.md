# Docking Agent 용어 사전

개인 실행 기록을 이해하기 위한 설명입니다. 정의와 이번 실행의 관찰을 구분했습니다.

## 도킹

- 읽기: 도킹
- 뜻: 단백질에 화합물이 붙을 때 가능한 3차원 배치를 계산하는 작업입니다.
- 이번 실험: 이번에는 c-Abl과 이마티닙의 결합 자세를 생성하고, 준비된 참조 자세와 비교했습니다.

## 단백질

- 읽기: 단백질
- 뜻: 아미노산 사슬이 접혀 만들어진 분자입니다. 접힌 구조의 모양과 화학적 성질이 기능에 관여합니다.
- 이번 실험: 이번 도킹의 단백질 쪽 입력은 1IEP에서 준비한 c-Abl 키나아제 도메인 구조입니다.

## 수용체

- 읽기: 수용체 / 리셉터
- 뜻: 도킹에서 화합물이 결합할 상대 구조를 가리키는 말입니다. 실제 생물학적 수용체 단백질만을 뜻하지는 않습니다.
- 이번 실험: receptor.pdbqt는 여기서 c-Abl 쪽 구조를 담은 파일 이름입니다.

## 타겟

- 읽기: 타겟
- 뜻: 약물이 작용하기를 기대하며 연구하는 대상입니다. 이 문서에서는 단백질을 뜻합니다.
- 이번 실험: 이번 예제의 타겟은 c-Abl입니다.

## 리간드

- 읽기: 리간드
- 뜻: 단백질 등에 결합하는 분자를 부르는 말입니다.
- 이번 실험: 이번 리간드는 이마티닙입니다. 리간드의 위치·방향·모양을 바꾸며 후보를 만듭니다.

## 화합물

- 읽기: 화합물
- 뜻: 서로 다른 원소의 원자들이 화학적으로 결합한 물질입니다.
- 이번 실험: 이번에 사용한 화합물 이마티닙은 도킹에서 리간드 역할을 합니다.

## 포켓

- 읽기: 포켓
- 뜻: 단백질 표면이나 내부에서 분자가 결합할 수 있는 홈이나 공간입니다. 홈이 있다고 약물이 잘 붙는 것은 아닙니다.
- 이번 실험: Vina 계열에는 튜토리얼이 제공한 알려진 포켓 주변의 박스를 지정했습니다.

## 1IEP

- 읽기: 원 아이 이 피
- 뜻: PDB에 등록된 구조 기록 번호입니다. 생쥐 유래 c-Abl 키나아제 도메인에 이마티닙(STI-571)이 결합한 X선 결정 구조입니다.
- 이번 실험: 우리는 이 기록을 바탕으로 준비된 Vina 튜토리얼 파일을 썼습니다. 여러 문제를 모은 데이터셋 이름은 아닙니다.

## c-Abl

- 읽기: 씨 에이블
- 뜻: 단백질에 인산기를 붙이는 기능을 가진 키나아제 단백질입니다.
- 이번 실험: 1IEP에는 이 단백질 전체가 아니라 키나아제 도메인이 들어 있습니다.

## 이마티닙

- 읽기: 이마티닙
- 뜻: Abl 등의 키나아제를 억제하는 소분자 약물입니다. STI-571이라는 이름으로도 불립니다.
- 이번 실험: 이번 도킹에서 c-Abl에 배치하는 리간드입니다.

## 도메인

- 읽기: 도메인
- 뜻: 단백질 안에서 하나의 구조·기능 단위를 이루는 부분입니다.
- 이번 실험: 1IEP의 c-Abl 키나아제 도메인은 효소 기능을 담당하는 부분입니다.

## 키나아제

- 읽기: 키나아제
- 뜻: 다른 분자에 인산기를 붙이는 반응을 촉진하는 효소입니다.
- 이번 실험: c-Abl은 단백질 키나아제이며, 이번 예제는 약물이 그 도메인에 결합한 구조를 사용합니다.

## 도킹 엔진

- 읽기: 도킹 엔진
- 뜻: 실제로 도킹 계산을 수행해 후보 자세와 점수를 만드는 프로그램입니다.
- 이번 실험: Vina·Vina-GPU·DiffDock-L이 계산 엔진이고, 우리가 만든 실행기는 이를 호출하고 결과를 기록합니다.

## 점수

- 읽기: 점수
- 뜻: 도구가 후보를 평가하거나 정렬하기 위해 계산한 숫자입니다.
- 이번 실험: Vina의 에너지와 DiffDock-L의 confidence는 정의가 다릅니다. 숫자만 나란히 놓고 같은 척도로 비교하면 안 됩니다.

## 모델

- 읽기: 모델
- 뜻: 입력에서 출력을 계산하는 수학적 규칙이나 학습된 계산 구조입니다.
- 이번 실험: DiffDock-L에서는 학습된 신경망 모델을 불러와 자세를 생성·평가합니다. 모델, 실행 프로그램, GPU 장치를 구분합니다.

## 체인

- 읽기: 체인
- 뜻: 단백질 구조에서 하나의 아미노산 사슬을 가리키며, A·B 같은 식별자로 구분합니다.
- 이번 실험: 팀 연결 설계에서 체인 정보는 어떤 사슬의 구조·포켓을 사용할지 지정하는 정보입니다.

## 결합 자세 · pose

- 읽기: 결합 자세 / 포즈
- 뜻: 화합물이 단백질에 대해 놓인 위치·방향과 내부의 비틀림 모양을 합친 배치입니다.
- 이번 실험: 같은 화합물도 여러 자세 후보로 출력됩니다. 화합물 자체가 서로 다른 물질이 된다는 뜻은 아닙니다.

## 후보

- 읽기: 후보
- 뜻: 프로그램이 가능한 답으로 생성한 하나의 결과입니다.
- 이번 실험: 이번 후보는 하나의 결합 자세 파일입니다. CPU는 3개, GPU는 5개, DiffDock-L은 10개를 출력했습니다.

## 순위 · rank

- 읽기: 순위 / 랭크
- 뜻: 도구가 자기 점수로 후보를 정렬한 순서입니다.
- 이번 실험: 1위는 그 도구가 가장 좋다고 고른 후보입니다. 참조에 가장 가까운 후보와 다를 수 있습니다.

## RMSD

- 읽기: 알 엠 에스 디
- 뜻: Root Mean Square Deviation. 대응하는 원자들의 위치 차이를 거리 하나로 요약한 값입니다.
- 이번 실험: 여기서는 준비된 참조와 비교합니다. 작을수록 가깝습니다. 0.889 Å는 친화도나 성공 확률이 아닙니다.

## Å · 옹스트롬

- 읽기: 옹스트롬
- 뜻: 원자·분자의 길이에 쓰는 단위입니다. 1 Å = 0.1 nm, 10 Å = 1 nm입니다.
- 이번 실험: 20 Å 박스는 한 변이 2 nm입니다. RMSD 0.89 Å는 영점팔구 옹스트롬이라고 읽습니다.

## 중원자

- 읽기: 중원자
- 뜻: 이 문서에서는 수소를 제외한 원자를 뜻합니다.
- 이번 실험: 리간드의 중원자 37개를 대응시켜 RMSD를 계산했습니다.

## 좌표계

- 읽기: 좌표계
- 뜻: 원자의 위치를 x·y·z 숫자로 나타낼 때 사용하는 공통 기준입니다.
- 이번 실험: 같은 좌표계에서 비교해야 위치 차이를 올바르게 측정할 수 있습니다. 이번에는 리간드를 따로 정렬하지 않았습니다.

## 포켓 박스

- 읽기: 포켓 박스
- 뜻: 도킹 프로그램이 화합물을 탐색할 3차원 범위입니다. 중심과 x·y·z 방향의 길이로 지정합니다.
- 이번 실험: 이번 Vina 계열에는 변 길이가 각각 20 Å인 같은 박스를 줬습니다.

## 참조 자세

- 읽기: 참조 자세
- 뜻: 예측 결과와 비교할 기준 배치입니다.
- 이번 실험: 실험 구조를 바탕으로 준비된 튜토리얼 리간드 좌표를 기준으로 사용했습니다. 점수가 가장 좋은 예측 후보를 뜻하지 않습니다.

## 결합 친화도

- 읽기: 결합 친화도 / 바인딩 어피니티
- 뜻: 화합물과 단백질이 얼마나 강하게 결합하는지에 관한 성질입니다.
- 이번 실험: 이번 실험은 자세를 비교한 것입니다. 실제 친화도 예측의 정확도는 평가하지 않았습니다.

## 도킹 에너지

- 읽기: 도킹 에너지
- 뜻: 프로그램의 점수식으로 계산한 결합의 유리함을 나타내는 수치입니다.
- 이번 실험: Vina 1위는 −13.270 kcal/mol입니다. 그 값을 실제 실험 친화도와 동일하게 해석할 수는 없습니다.

## kcal/mol

- 읽기: 킬로칼로리 퍼 몰
- 뜻: 물질의 양 1몰당 에너지를 나타내는 단위입니다.
- 이번 실험: Vina 계열 도킹 에너지의 단위입니다. 이번 정렬에서는 더 낮은 점수가 우선입니다.

## confidence

- 읽기: 컨피던스
- 뜻: DiffDock-L에서 생성된 자세를 정렬하는 학습된 평가 모델의 점수입니다.
- 이번 실험: 이번 1위 점수는 −3.30입니다. 이 숫자 자체는 정답 확률이나 결합 친화도가 아닙니다.

## AutoDock Vina

- 읽기: 오토독 비나 / 비나
- 뜻: 정해진 점수식을 계산하면서 화합물의 위치·방향·비틀림을 바꿔 좋은 자세를 탐색하는 도킹 프로그램입니다.
- 이번 실험: 이번에는 CPU용 1.2.7을 사용하고 알려진 포켓 안에서 탐색했습니다.

## Vina-GPU 2.1

- 읽기: 비나 지피유
- 뜻: Vina 계열 탐색을 GPU 병렬 계산과 별도의 최적화 구현으로 수행하는 프로그램입니다.
- 이번 실험: CPU Vina 1.2.7과 프로그램 버전·탐색 구현이 다릅니다. 하드웨어만 바꾼 완전히 같은 계산은 아닙니다.

## DiffDock-L

- 읽기: 디프독 엘
- 뜻: 결합 구조의 패턴을 학습한 확산 생성 모델로 리간드의 위치·방향·비틀림을 조정하고, 별도의 confidence 모델로 후보를 정렬하는 도킹 방법입니다.
- 이번 실험: 이번에는 포켓 박스 없이 전체 단백질을 탐색했습니다. 이미 준비된 단백질 구조를 사용하며, 단백질을 새로 접는 co-folding과 구분합니다.

## 무작위 탐색

- 읽기: 무작위 탐색
- 뜻: 모든 자세를 전부 확인하기 어려워 여러 시작 배치와 변화 경로를 난수로 선택하며 탐색하는 방식입니다.
- 이번 실험: 탐색 경로가 달라지면 최종 후보도 달라질 수 있습니다. 같은 시드도 서로 다른 프로그램의 경로를 같게 만들지는 않습니다.

## 시드 · seed

- 읽기: 시드
- 뜻: 프로그램이 쓰는 의사난수의 시작 상태를 정하는 숫자입니다.
- 이번 실험: 이번 시드는 20261009입니다. 동일한 프로그램·입력·설정을 맞춰 재현할 때 쓰며, 서로 다른 엔진의 결과 일치를 보장하지 않습니다.

## exhaustiveness

- 읽기: 이그조스티브니스
- 뜻: CPU Vina가 탐색에 들일 노력을 조절하는 옵션입니다.
- 이번 실험: 이번에는 8을 사용했습니다. CPU 코어 수나 출력 후보 수와 다르고, GPU thread=8000과 같은 단위가 아닙니다.

## thread

- 읽기: 스레드
- 뜻: 일반적으로 계산 작업의 실행 흐름을 뜻합니다. Vina-GPU의 이 옵션은 병렬 도킹 탐색 경로의 규모를 정합니다.
- 이번 실험: 이번 thread=8000은 CPU 코어 8,000개나 후보 8,000개를 출력한다는 뜻이 아닙니다.

## search_depth

- 읽기: 서치 뎁스
- 뜻: Vina-GPU의 각 탐색 경로에서 수행하는 탐색 반복 수를 조절하는 옵션입니다.
- 이번 실험: 이번 GPU 요청에서는 명시하지 않고 엔진이 정하는 기본값을 사용했습니다.

## RILC-BFGS

- 읽기: 알 아이 엘 씨 비 에프 지 에스
- 뜻: Reduced Iteration and Low Complexity BFGS. Vina-GPU 2.1에서 자세의 점수를 개선하는 국소 최적화 계산을 빠르게 수행하도록 바꾼 방법입니다.
- 이번 실험: 이번 GPU 실행에서는 이 옵션을 켰습니다. CPU와 탐색 구현이 달라지는 요인 중 하나입니다.

## BFGS

- 읽기: 비 에프 지 에스
- 뜻: Broyden–Fletcher–Goldfarb–Shanno. 현재 배치를 조금씩 움직이며 더 좋은 점수 쪽으로 개선하는 수치 최적화 방법입니다.
- 이번 실험: Vina 계열의 자세 미세 조정에 쓰입니다. 분자나 AI 모델 이름이 아닙니다.

## 최적화

- 읽기: 최적화
- 뜻: 위치나 각도 같은 값을 바꾸며 목적 점수를 더 좋게 만드는 과정입니다.
- 이번 실험: 도킹에서는 화합물의 배치를 조정합니다. 수학적 점수가 좋아졌다고 실제 결합이 증명되는 것은 아닙니다.

## 병렬

- 읽기: 병렬
- 뜻: 여러 계산 작업을 동시에 진행하는 방식입니다.
- 이번 실험: Vina-GPU는 많은 탐색 경로를 GPU에서 병렬로 계산합니다. CPU도 여러 코어를 이용할 수 있습니다.

## 확산 생성 모델

- 읽기: 확산 생성 모델
- 뜻: 학습 때 배치를 점차 흐트러뜨리는 과정을 이용하고, 생성할 때 학습한 역방향 조정을 반복해 후보를 만드는 모델입니다.
- 이번 실험: DiffDock은 리간드의 위치·회전·비틀림 공간에서 이 과정을 사용합니다. 이미지를 생성하는 작업은 아닙니다.

## 평행이동

- 읽기: 평행이동
- 뜻: 화합물 전체를 x·y·z 방향으로 옮기는 변화입니다.
- 이번 실험: 단백질의 어느 위치에 놓을지를 바꿉니다.

## 회전

- 읽기: 회전
- 뜻: 화합물 전체가 향하는 방향을 바꾸는 변화입니다.
- 이번 실험: 같은 포켓에 들어가도 화합물의 앞뒤와 방향이 다르면 결합 자세가 달라집니다.

## 비틀림

- 읽기: 비틀림
- 뜻: 회전 가능한 결합을 축으로 분자의 일부를 돌리는 변화입니다.
- 이번 실험: 화합물 전체의 방향을 돌리는 것과 달리, 분자 내부의 모양이 바뀝니다.

- 이번 실험: Vina는 이 점수식과 그 변화 방향을 이용해 화합물 배치를 개선합니다.

## 학습

- 읽기: 학습
- 뜻: 사례를 이용해 모델 내부의 수치를 조절하며 입력에서 원하는 출력을 계산하도록 맞추는 과정입니다.
- 이번 실험: DiffDock은 알려진 결합 구조에서 흐트러뜨린 배치를 이용해 조정 방향을 학습합니다. 이번 작업에서는 제공된 가중치로 실행했습니다.

## 신경망

- 읽기: 신경망
- 뜻: 여러 계산 층과 학습된 수치로 입력의 특징에서 출력을 계산하는 모델입니다.
- 이번 실험: DiffDock은 현재 단백질·리간드 구조를 보고 이동·회전·비틀림 조정에 쓰는 수치를 계산합니다.

## 생성 모델

- 읽기: 생성 모델
- 뜻: 입력 조건에 맞는 새로운 후보를 만들어 내도록 학습된 모델입니다.
- 이번 실험: DiffDock의 생성 모델은 여러 결합 자세를 만듭니다. 최종 후보 순위는 별도의 평가 모델이 결정합니다.

## 평가 모델

- 읽기: 평가 모델
- 뜻: 후보의 특성을 보고 평가 점수를 계산하도록 학습된 모델입니다.
- 이번 실험: DiffDock의 confidence 모델은 생성된 자세를 평가해 순위를 정합니다. 이 점수가 실제 정답 확률로 보정됐다는 뜻은 아닙니다.
